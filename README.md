# Abdelrahman Hesham — Portfolio

Source of the personal portfolio site for AI, software and data work: https://abdelrahman-hesham-portfolio.vercel.app

## What is here

A static site with no build step: `index.html`, `styles.css` and plain JavaScript (`app.js` for content and case studies, `catalog.js`, `work-scroll.js`, `interactions.js`, `interaction-math.js`, `avatar-rig-data.js`, `source-shots.js`). `assets/` holds the avatar illustration, project screenshots and source excerpts, and small evidence files linked from the case studies (`assets/evidence/`). `vercel.json` serves the folder as-is.

This snapshot contains exactly the files of the deployed site. Local reviews, drafts and original identity photos are not included.

## Running locally

Serve the folder with any static file server, for example:

```
python -m http.server 8000
```
